# Roadmap

この文書はMVP後の構想を記録する。ここにある項目は、個別に仕様化されるまでMVPの実装要件ではない。

## 次段階: Prod構築と社内利用

- Prod環境のapplyと運用開始
- Easy Authの許可対象を社内ユーザーへ拡大
- Entra IDのユーザー・グループ単位の権限管理
- 会話履歴とRAG文書のアクセス制御
- 認証済みユーザーIDを履歴の所有者識別子として利用
- 一般公開を避けた社内向けネットワーク構成

## RAG拡張

- LLMまたは分類器によるRAG利用の自動判定
- 判定結果の表示と手動上書き
- Blob Storageの変更を検知した文書の自動取り込み
- 文書管理画面、再インデックス、更新状態の表示
- 文書アクセス権を反映した検索結果の絞り込み

## セキュリティと運用強化

- VNet統合とPrivate Endpoint
- Key Vaultの運用強化とシークレットローテーション
- 監査ログと管理者向け運用画面
- 個人情報の検出・マスキング
- 災害復旧、バックアップ、復元手順

## 開発体験

- Dependabotによる依存関係更新PR
- UIのE2Eテスト
- ステージング環境の追加
- 負荷試験とコスト最適化
